## Agent skills

### Issue tracker

Issues live in GitHub Issues for Balauruu/YT-StrategizeR (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Labels

Default flow labels: `state:*`, `type:*`, `design:building` and `wayfinder:*`. See `docs/agents/labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Designs

Each effort's working files go in `docs/designs/<slug>/`, its finished design in `docs/designs/<slug>.md`, indexed in `docs/designs/SITEMAP.md`.
